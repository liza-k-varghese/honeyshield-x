# HoneyShield X — Universe 2.0 Visual Design System

## 1. Living Observatory Environmental Layers

```
Layer 0: Deep Obsidian Radial Gradient (#070d1e to #010207)
Layer 1: Procedural Constellation & Starfield Canvas (75 subtle glowing motes)
Layer 2: Technical Cyan Grid Overlay (40px x 40px, rgba(0, 229, 255, 0.03))
Layer 3: CRT Scanlines Texture (repeating 1px / 2px horizontal bands)
Layer 4: Concentric Rotating Orbital Rings (720px, 520px, 320px)
Layer 5: Quadratic Bézier Luminous Energy Conduits
Layer 6: Event Singularity Core & Four Agent Territory Outposts
Layer 7: Dynamic Character Locomotion & Packet Transit
Layer 8: Observatory Instruments & Holographic Inspection Consoles
```

## 2. Core Palette & Color Tokens

- **Cosmic Obsidian:** `#010207`, `#030611`, `#070d1e`
- **Dark Steel & Glass:** `rgba(6, 11, 22, 0.82)`, `rgba(8, 14, 28, 0.82)`
- **Cyan Accent (HoneyShield Core / NEXUS):** `#00E5FF` (hover `#67E8F9`)
- **Electric Blue (SCOUT Sensor Frontier):** `#3B82F6` (hover `#60A5FA`)
- **Deep Purple (ORACLE Intelligence Sanctum):** `#A855F7` (hover `#C084FC`)
- **Crimson Red (SENTINEL Response Bastion):** `#EF4444` (hover `#F87171`)
- **Emerald Green (Authentic Live Telemetry & Success):** `#10B981` (hover `#34D399`)
- **Amber Gold (Synthetic Demo & Caution):** `#F59E0B` (hover `#FBBF24`)

## 3. Four Distinct Territory Visual Identities

| Agent | Visual Metaphor | Key Graphic Signatures | Operational Meaning |
| :--- | :--- | :--- | :--- |
| **SCOUT** | Sensor Frontier | Radar sweep conic gradient (`hsx-radar-sweep`), sensor node badges (SSH 2222, HTTP 8080) | Honeytrap connection capture, canary trips |
| **NEXUS** | Processing Nexus | Flowing circuit bus (`hsx-circuit-bus`), PostgreSQL 17 outbox indicators | ACID queue commit, monotonic serialization |
| **ORACLE** | Intelligence Sanctum | Floating holographic risk glyph (`hsx-intel-glyph`), IOC correlation paths | Threat actor attribution, risk normalization |
| **SENTINEL** | Response Bastion | Barrier forcefield pulse (`hsx-barrier-shield`), alert triage conduits | Emergency containment, WebSocket & Android push |

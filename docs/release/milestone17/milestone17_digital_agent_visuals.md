- The landing page and SOC command center embed interactive 3D `TiltCard` containers for each agent.
- Card tilt calculates radial cursor lighting reflecting the agent's signature wavelength.
- Agent telemetry cards display live status (`ACTIVE`, `INGESTING`, `ANALYZING`, `ARMED`), event counts, and real-time processing throughput.

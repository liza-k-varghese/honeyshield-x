## 1. Identification of Build Generation Process

The APK artifact `honeyshield-mobile-v1.0.0-rc5-debug.apk` was generated by:
- **Build Mechanism:** Custom shell script [`scripts/build_mobile_apk.sh`](file:///home/liza/HoneyShield-X/scripts/build_mobile_apk.sh)
- **Toolchain Invocations:**
  1. `keytool` (OpenJDK 25) generating debug keystore.
  2. `javac --release 8 -Xlint:-options` compiling 5 isolated Java classes in `mobile/android/src/com/honeyshield/soc/`.
  3. `jar cf` creating `classes.jar`.
  4. `/usr/bin/d2j-jar2dex` converting `classes.jar` into `classes.dex`.
  5. `esbuild mobile/index.js --bundle --minify --platform=neutral --packages=external --outfile=assets/index.android.bundle`.
  6. `zip -r -9` packaging raw text manifest, raw images, DEX, and JS bundle into an unaligned zip archive.
  7. `jarsigner -sigalg SHA256withRSA -digestalg SHA-256` signing the zip archive.

### 3. Security Findings & Active Credential Status

1. **Production Debug Bypass Lockdown:**
   - Client-side query parameters (`?debug=1`, `?hud=1`) and console globals (`window.__HSX_DEBUG__`) cannot activate telemetry in production builds.
   - Any unauthorized listener access scrubs `window.__HSX_RELAY_STATE__`.
2. **Administrative Credential Status:**
   - **In Development Mode:** Baseline demo accounts are active in memory on port 8000.
   - **In Production Mode:** Baseline demo accounts are strictly rejected; the backend raises `RuntimeError` at boot if `HONEYSHIELD_OPERATORS_JSON` is missing.
   - **Current Blocker:** Production secrets must be generated by the operator and injected into the runtime environment before production startup can proceed.

### 5. Production Destination Requirements

Before deploying to the final production environment, the operator must verify:
- Host operating system: Linux (Parrot OS, Debian 12+, Ubuntu 22.04+, or RHEL 9+).
- Hardware sizing: Minimum 4 vCPU, 8 GB RAM, 50 GB SSD storage.
- External Reverse Proxy: Nginx or Caddy terminating TLS 1.3 with OWASP headers (`nosniff`, `DENY`, `HSTS`).
- WebSocket Proxying: Reverse proxy configured with `Upgrade $http_upgrade` and `Connection "upgrade"`.
- Environment Variables:
  - `APP_ENV=production`
  - `DATABASE_URL=postgresql+psycopg://...`
  - `REDIS_URL=redis://...`
  - `SECRET_KEY=<32_byte_csprng_token>`
  - `HONEYSHIELD_OPERATORS_JSON=[{...}]`

### 7. Rollback Procedure

If a critical operational issue occurs during or immediately after deployment:
1. **Frontend Rollback:** Point the Nginx root back to the previous stable release directory:
   ```bash
   ln -sfn /opt/honeyshield/frontend/dist-rc5 /var/www/honeyshield
   systemctl reload nginx
   ```
2. **Backend Rollback:** Revert backend repository commit or restart previous systemd service target:
   ```bash
   systemctl restart honeyshield-api-rc5
   ```
3. **Database Migration Rollback (if applicable):**
   ```bash
   alembic downgrade -1
   ```
4. **Data Restoration (Disaster Scenario):**
   ```bash
   psql -U honeyshield -d honeyshield < /var/backups/honeyshield/pre_deploy_backup.sql
   ```

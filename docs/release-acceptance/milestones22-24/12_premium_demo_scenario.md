## 2. Deterministic Safe Demo Scenario

The demonstration scenario simulates an external adversary probing an enterprise perimeter:
1. **Adversary Action:** Adversary queries a decoy database backup (`database_backup.sql`).
2. **HoneyShield X Ingestion:** Canary trap generates high-confidence alert ($1.0$).
3. **Correlation:** Detection engine flags simultaneous RCE exploit attempt on `/api/v1/auth`.
4. **Threat Intel:** ORACLE attributes adversary infrastructure to APT29.
5. **Operator Triage:** SOC analyst transitions to Forensics with 1 click to view process ancestry (`bash` &rarr; `python` &rarr; `nc`).
6. **Universe Visualization:** The Spatial Universe renders the event packet progressing through SCOUT &rarr; NEXUS &rarr; ORACLE &rarr; SENTINEL.

## 3. Strict Demo Mode Isolation Guarantees

- **Explicit Visual Watermark:** While Demo Mode is active, an unambiguous banner indicates: `DEMO MODE // SYNTHETIC RELAY`.
- **Zero Production Mutation:** Synthetic demo packets operate entirely in-memory within client state; they never invoke backend containment APIs, firewall block endpoints, or insert synthetic records into live database tables.
